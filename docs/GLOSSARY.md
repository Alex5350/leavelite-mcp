# Glossary

Terms used across LeaveLite's documentation: plain English first, precisely second. Business
terms come first (the leave domain), engineering terms second.

| Term | In plain English | Precisely |
|---|---|---|
| Accrual | Leave that builds up over time, like a paycheck made of days off: so many hours every month, or a lump sum granted at the start of the year. | Hours credited under an `AccrualPolicy` (monthly fractions or an upfront yearly grant). Balances are computed, never stored: the pure `AccrualBalanceCalculator` derives them from the employee, the policy and the date ([ADR 0005](adr/0005-accrual-engine-purity.md)). |
| Tenure gate | A waiting period before leave starts building up: "after your first three months you start earning vacation days." | `minTenureMonths` on the policy. Before the gate passes, nothing accrues for that leave type; consumed hours still apply, so an ineligible employee can be overdrawn. |
| Carry-over cap | The "use it or lose it" limit: only some unused hours cross into the new year, the rest expire. | `carryOverCapHours` applied at the calendar-year roll; the chosen semantics are documented in the calculator rather than hidden behind configuration ([ADR 0005](adr/0005-accrual-engine-purity.md)). |
| Minimum staffing | The rule that approving leave can never leave a team with nobody working: at least one other member must be available on every day of the absence. | `MinimumStaffingSpecification`, checked when a manager decides, against the rest of the team's approved leave; a violation returns `LeaveRequest.MinimumStaffingNotMet`. |
| Approval authority | Only the right person can say yes: a request is decided by the manager of the same team as the employee, nobody else. | The server rejects decisions by anyone who is not a same-team Manager: `Employee.ApproverNotTeamManager` ([ADR 0006](adr/0006-error-surfacing.md)). |
| Leave balance | The hours available to take: what has accrued minus what approved leave has already consumed. | Accrued minus consumed hours for a leave type as of a date. Weekends and organization holidays never consume balance. |
| Holiday-aware consumption | A holiday that falls inside your vacation does not burn a vacation day; only working days count against the balance. | Working days are Monday to Friday minus organization holidays; requested hours are working days times 8h (`WorkSchedule.StandardHoursPerDay`). |
| Working day | A day that actually counts as a day off if you take leave: any weekday that is not an organization holiday. | A date in the leave range that is neither a weekend day nor in the team's holiday calendar; the unit all hour math is done in. |
| MCP | The standard plug shape that lets AI assistants use external tools safely: the assistant asks, the server answers, and the server's rules decide what is allowed. | Model Context Protocol: an open protocol (JSON-RPC 2.0 based) for connecting AI clients to servers. LeaveLite exposes its whole surface this way, so any MCP client (Claude Desktop, Claude Code, IDE agents) can connect ([ADR 0002](adr/0002-mcp-sdk-and-transport.md)). |
| Tool | Something the assistant can *do* through the server, such as "submit a leave request." The server lists its tools when the assistant connects, with a description of when to use each. | An MCP operation invoked with `tools/call`. LeaveLite serves ten leave tools; tool descriptions double as the UX for LLM callers ([ADR 0006](adr/0006-error-surfacing.md)). |
| Resource | Reference material the assistant can look up rather than act on: the policy list, the teams, the holiday calendar. | Read-only data addressable by URI (`leavelite://policies`, `leavelite://teams`, `leavelite://holidays/{year}`) and retrieved with `resources/read`. |
| Prompt | A canned starting instruction the server hands to the assistant, such as "audit this team's coverage for the month using the tools." | A parameterized prompt template (`team-coverage-review`) retrieved with `prompts/get`. |
| Streamable HTTP | How the assistant and the server talk: each request is one ordinary HTTP POST carrying a complete message, and the answer may stream back. | The MCP HTTP transport used here: every POST is self-contained JSON-RPC, responses may arrive as server-sent events; hosted at `/mcp` by ASP.NET Core ([ADR 0002](adr/0002-mcp-sdk-and-transport.md)). |
| Stateless server | The server keeps no memory of you between requests; each request carries everything needed, so any copy of the server can serve it. | `Stateless = true` on the SDK HTTP transport: no session handshake, no session affinity, trivial load balancing, simpler integration tests ([ADR 0002](adr/0002-mcp-sdk-and-transport.md)). |
| CQRS | Splitting "change something" requests from "look something up" requests so each stays simple and findable. | Commands and queries as `ICommand`/`IQuery` records handled by `ICommandHandler`/`IQueryHandler` implementations, registered by assembly scanning, with no mediator package ([ADR 0004](adr/0004-cqrs-without-mediator.md)). |
| Domain events | "Something happened" notices the core logic publishes (for example: this approval left the balance under one workday) without caring who listens. | e.g. `LowBalanceWarningDomainEvent`, raised when a request leaves less than one workday of balance, dispatched after save ([ADR 0007](adr/0007-domain-events-channel.md)). |
| Bounded channel | A waiting line of fixed length between the core and a background worker: if the line is full, a notice is dropped (and logged) instead of jamming the work. | `System.Threading.Channels.Channel<T>` with capacity 64 and drop-write behavior, drained by the `LowBalanceAlertWorker` background service ([ADR 0007](adr/0007-domain-events-channel.md)). |
| Integration test at protocol level | Testing the server by talking to it exactly the way a real assistant would, over the real protocol, instead of calling its internal methods. | 27 tests boot the real host with `WebApplicationFactory` and connect the official MCP C# client over HTTP: handshake, discovery, tool calls, a full write flow ([ADR 0008](adr/0008-protocol-testing.md)). |
